# Retail Sales Data Analysis (EDA)

## Project Overview
This project explores a retail sales dataset using Python to understand sales performance, customer purchasing behavior, and product category trends. Exploratory Data Analysis (EDA) techniques are used to summarize the data, visualize patterns, and identify actionable business insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
The dataset contains 1,000 retail transactions and 9 original columns:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Project Workflow
1. Load and inspect the retail sales dataset.
2. Check dataset dimensions, column names, and data types.
3. Convert the transaction date column into datetime format.
4. Identify missing values and duplicate records.
5. Calculate descriptive statistics, including mean, median, mode, and standard deviation.
6. Analyze monthly and quarterly sales trends.
7. Group customers by age and analyze gender distribution.
8. Compare product categories by quantity sold and revenue generated.
9. Use a correlation matrix and heatmap to examine relationships between numerical variables.
10. Analyze revenue across customer age groups.
11. Summarize key findings and provide business recommendations.

## Key Findings
- Total transactions analyzed: 1,000.
- Total revenue: 456,000 in the dataset's currency.
- Total quantity sold: 2,514 units.
- Average transaction value: 456.
- Highest-revenue product category: Electronics.
- Highest-quantity product category: Clothing.
- Highest-revenue customer age group: 46–55 years.
- Missing values and duplicate records: None identified.
